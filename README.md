# Путь от 1 SOL

Дневник торговых сессий: баланс в SOL и долларах, календарь результатов, график
пополнений и выводов, карточка дня и таймер отрезков. Статическая страница,
ставится на айфон как приложение.

Репозиторий приватный, поэтому хостинг — **Netlify**: GitHub Pages на бесплатном
плане отдаёт сайты только из публичных репозиториев.

## Подключить хостинг (один раз)

1. [app.netlify.com](https://app.netlify.com) → **Log in with GitHub**.
2. **Add new site** → **Import an existing project** → **GitHub**.
3. Дать Netlify доступ к репозиторию `sol` и выбрать его.
4. Настройки сборки не трогать — всё уже описано в `netlify.toml`. Нажать **Deploy**.

Дальше каждый `git push` в `main` выкатывается сам. Адрес сайта можно поменять на
понятный: **Site configuration → Change site name**.

## Поставить на айфон

Открыть адрес сайта в Safari → **Поделиться** → **На экран «Домой»**.
Дальше открывается без адресной строки, работает без интернета и помнит записи.

Если приложение уже стояло со старого адреса — удалить его с экрана и добавить
заново: у нового адреса своё хранилище.

## Синхронизация

Данные лежат в приватном gist на GitHub — поэтому телефон и компьютер видят одно
и то же. В репозиторий записи не попадают.

1. Сделать токен: [github.com/settings/tokens](https://github.com/settings/tokens/new?scopes=gist&description=Sol%20tracker)
   → **Generate new token (classic)** → отметить **только** галочку `gist`.
2. В приложении: блок **Синхронизация** → **Настроить** → вставить токен → **Подключить**.
3. Повторить на каждом устройстве.

Токен лежит только в браузере устройства и уходит только на `api.github.com`.
Без токена всё тоже работает — записи просто остаются на одном устройстве.

Правило слияния: по каждому дню побеждает более поздняя запись (`updatedAt`).
Удалённый день хранится «надгробием» (`deleted: true`), чтобы удаление доезжало
на второе устройство, и вычищается через 120 дней.

Резервная копия — кнопки **Выгрузить бэкап** / **Загрузить бэкап** в том же блоке.

## Про приватность

Приватный репозиторий прячет исходники. Сам сайт по своему адресу доступен
любому, кто знает ссылку, — так устроен любой статический хостинг. `robots.txt` и
`noindex` держат его вне поисковиков. Пароль на сайт у Netlify есть только на
платном тарифе.

Gist тоже стоит понимать правильно: GitHub называет его «secret», но это значит
«не в списке», а не «под замком». Кто знает его 32-символьный идентификатор,
прочитает содержимое без токена. Запись — только с токеном.

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html` | Всё приложение: вёрстка, стили, логика |
| `sw.js` | Офлайн: страница из сети, статика из кэша, `api.github.com` не трогается |
| `manifest.webmanifest` | Имя, иконки, запуск в полноэкранном режиме |
| `netlify.toml` | Что публиковать и какие заголовки кэширования ставить |
| `fonts/` | Manrope и JetBrains Mono локально — без обращений к Google |
| `icon-*.png` | Иконки, в том числе `icon-180.png` для экрана «Домой» |

Страница собирается из артефакта Claude, но не равна ему: на сайте нет `window.claude`,
поэтому база заменена на синхронизацию через gist, а выгрузка PNG — на обычное
сохранение файла.

**После изменения `index.html` обязательно поднять `VERSION` в `sw.js`** — иначе у
уже установленных приложений останется старая версия из кэша.
