# Путь от 1 SOL

Дневник торговых сессий: баланс в SOL и долларах, календарь результатов, таймер отрезков.
Статическая страница, ставится на айфон как приложение.

**Адрес:** https://mylifeitsbest.github.io/sol/

## Поставить на айфон

Открыть адрес в Safari → **Поделиться** → **На экран «Домой»**.
Дальше открывается без адресной строки, работает без интернета и помнит записи.

## Синхронизация

Данные лежат в приватном gist на GitHub — поэтому телефон и компьютер видят одно и то же.

1. Сделать токен: [github.com/settings/tokens](https://github.com/settings/tokens/new?scopes=gist&description=Sol%20tracker)
   → **Generate new token (classic)** → отметить **только** галочку `gist`.
2. В приложении: блок **Синхронизация** → **Настроить** → вставить токен → **Подключить**.
3. Повторить на каждом устройстве.

Токен лежит только в браузере устройства, в репозиторий не попадает и уходит только на `api.github.com`.
Без токена всё тоже работает — записи просто остаются на одном устройстве.

Правило слияния: по каждому дню побеждает более поздняя запись (`updatedAt`).
Удалённый день хранится «надгробием» (`deleted: true`), чтобы удаление доезжало на второе устройство,
и вычищается через 120 дней.

Резервная копия — кнопки **Выгрузить бэкап** / **Загрузить бэкап** в том же блоке.

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html` | Всё приложение: вёрстка, стили, логика |
| `sw.js` | Офлайн: страница из сети, статика из кэша, `api.github.com` не трогается |
| `manifest.webmanifest` | Имя, иконки, запуск в полноэкранном режиме |
| `fonts/` | Manrope и JetBrains Mono локально — без обращений к Google |
| `icon-*.png` | Иконки, в том числе `icon-180.png` для экрана «Домой» |

После изменения `index.html` поднять `VERSION` в `sw.js` — иначе у уже установленных
приложений останется старая версия из кэша.
