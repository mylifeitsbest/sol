# Путь от 1 SOL

Дневник торговых сессий: баланс в SOL и долларах, календарь результатов, график
пополнений и выводов, карточка дня и таймер отрезков. Статическая страница,
ставится на айфон как приложение.

**Адрес:** https://mylifeitsbest.github.io/sol/

## Поставить на айфон

Открыть адрес в Safari → **Поделиться** → **На экран «Домой»**.
Дальше открывается без адресной строки, работает без интернета и помнит записи.

## Синхронизация

Данные лежат в приватном gist на GitHub — поэтому телефон и компьютер видят одно
и то же. В репозиторий записи не попадают.

Устройство подключается **ссылкой вида `…/sol/#sync=<адрес хранилища>`**. При
открытии страница запоминает адрес, вычищает его из адресной строки и дальше
тянет статистику сама. Адрес хранилища намеренно не лежит в репозитории —
он живёт только в этой ссылке и в памяти браузера.

Секретный gist читается по идентификатору без авторизации, поэтому **для
просмотра статистики токен не нужен**. Токен нужен только чтобы новые записи с
этого устройства уходили в облако:

1. Сделать токен: [github.com/settings/tokens](https://github.com/settings/tokens/new?scopes=gist&description=Sol%20tracker)
   → **Generate new token (classic)** → отметить **только** галочку `gist`.
2. В приложении: блок **Синхронизация** → **Настроить** → вставить → **Подключить**.

В это же поле можно вставить и адрес хранилища — страница сама разберёт, что
ей дали: строка из hex это адрес, `ghp_…` это токен. Пригодится на айфоне:
приложение с экрана «Домой» имеет собственное хранилище, отдельное от Safari,
поэтому ссылка, открытая в Safari, его не настраивает.

Оба значения хранятся только в этом браузере и уходят только на `api.github.com`.
Без подключения всё тоже работает — записи просто остаются на одном устройстве.

Правило слияния: по каждому дню побеждает более поздняя запись (`updatedAt`).
Удалённый день хранится «надгробием» (`deleted: true`), чтобы удаление доезжало
на второе устройство, и вычищается через 120 дней.

Резервная копия — кнопки **Выгрузить бэкап** / **Загрузить бэкап** в том же блоке.

## Про приватность

Репозиторий публичный, потому что GitHub Pages на бесплатном плане отдаёт сайты
только из публичных репозиториев. Закрыть его — значит потерять сайт: проверено,
Pages при этом не выключается, а удаляется целиком, и включать его приходится
заново.

Прятать тут особо нечего. Сайт — статическая страница: кто открыл адрес, тот
через «Просмотр кода страницы» видит ровно то же, что лежит в репозитории.
Приватный репозиторий скрыл бы только историю коммитов и поиск по GitHub.
Записей в репозитории нет — они в gist. `robots.txt` и `noindex` держат страницу
вне поисковиков.

Gist тоже стоит понимать правильно: GitHub называет его «secret», но это значит
«не в списке», а не «под замком». Кто знает его 32-символьный идентификатор,
прочитает содержимое без токена. Запись — только с токеном.

### Если всё же захочется закрыть исходники

Нужен хостинг, умеющий в приватные репозитории, — например Netlify (бесплатно).
`netlify.toml` в репозитории уже настроен: что публиковать и какие заголовки
кэширования ставить.

1. [app.netlify.com](https://app.netlify.com) → войти. Если аккаунт заводился
   почтой и паролем, кнопка «Log in with GitHub» не сработает: она пытается
   создать второй аккаунт на ту же почту. Надо войти почтой, а GitHub привязать
   в **Settings → Connected accounts**.
2. **Add new site** → **Import an existing project** → **GitHub** → выбрать репозиторий.
3. Настройки сборки не трогать. **Deploy**.

Адрес после переезда сменится, так что приложение на айфоне надо будет добавить
заново и один раз вставить токен. Записи не пострадают — они в gist.

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html` | Всё приложение: вёрстка, стили, логика |
| `sw.js` | Офлайн: страница из сети, статика из кэша, `api.github.com` не трогается |
| `manifest.webmanifest` | Имя, иконки, запуск в полноэкранном режиме |
| `netlify.toml` | Про запас, на случай переезда на Netlify |
| `fonts/` | Manrope и JetBrains Mono локально — без обращений к Google |
| `icon-*.png` | Иконки, в том числе `icon-180.png` для экрана «Домой» |

Страница собирается из артефакта Claude, но не равна ему: на сайте нет
`window.claude`, поэтому база заменена на синхронизацию через gist, а выгрузка
PNG — на обычное сохранение файла.

**После изменения `index.html` обязательно поднять `VERSION` в `sw.js`** — иначе у
уже установленных приложений останется старая версия из кэша.
